# Auditoría de métricas PE5

La tabla completa M1--M6 se encuentra en el informe y en `03_Matriz_Trazabilidad/PE5_Matrices_FabroGym.xlsx`.

Para M6 se incluye evidencia reproducible adicional:
- `Registro_Reinspeccion_M6.md`: alcance, método e interpretación.
- `reinspeccion_m6.py`: script de verificación documental.
- `resultado_reinspeccion_m6.txt`: salida de la ejecución sobre la ERS final.

Ejecutar desde la raíz:

```bash
python3 04_Auditoria_Metricas/reinspeccion_m6.py
```
