# Protocolo de walkthrough no técnico

Este archivo es un instrumento preparado para una ejecución posterior. No contiene participantes, respuestas ni resultados simulados.

## Perfiles objetivo

- Responsable del gimnasio: panel, membresías, inventario y reportes.
- Recepción: clientes, membresías, pagos, asistencia y ventas.
- Instructor: creación, asignación, ajuste y seguimiento de rutinas.

## Secuencia de aplicación

1. Explicar el propósito de la sesión y obtener la autorización correspondiente.
2. Identificar la versión del prototipo utilizada.
3. Entregar las tareas sin explicar cómo resolverlas.
4. Registrar dudas, errores, tiempo, ayuda solicitada y comentarios.
5. Consolidar cada observación como hallazgo, con requisito afectado.
6. Documentar la decisión del equipo: aceptar, rechazar o postergar.
7. Actualizar ERS, modelos, backlog y trazabilidad cuando corresponda.

## Campos de registro

| Campo | Contenido |
|---|---|
| Código de sesión | WNT-01, WNT-02 o WNT-03 |
| Perfil | Responsable, Recepción o Instructor |
| Fecha y versión | Fecha real y versión del prototipo |
| Tarea | Acción solicitada |
| Resultado observado | Completada, con ayuda o no completada |
| Hallazgo | Descripción objetiva |
| Requisito afectado | Identificador RF/RNF |
| Decisión | Aceptar, rechazar o postergar |
| Evidencia | Archivo o registro generado durante la sesión |
